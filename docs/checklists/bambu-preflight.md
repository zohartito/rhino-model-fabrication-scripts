# Bambu Preflight

Use before sending a plate to the P2S or A1.

- Import the intended final STL, not an older trial.
- Confirm printer profile and nozzle.
- Confirm filament.
- Confirm units imported correctly.
- Confirm parts are on the build plate.
- For returns, confirm the outer-subframe edge is on the bed.
- Slice.
- Scrub the layer slider from bottom to top.
- Check that all expected parts appear at the appropriate layers.
- Check support amount. Huge support usually means wrong orientation.
- Check estimated time and filament against known similar successful plates.
- Only print after the preview matches the proven reference orientation.
