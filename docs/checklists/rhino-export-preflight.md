# Rhino Export Preflight

Use before exporting STL, laser curves, or a saved working file.

- Confirm file units.
- Confirm model scale.
- Confirm the active file is the intended source.
- Save or duplicate the source if you are about to run destructive scripts.
- Isolate the target layer or target objects.
- Count expected objects.
- For print parts, run `Check`.
- For print parts, confirm final objects are closed valid polysurfaces.
- For laser files, confirm curves are planar and organized by color/layer.
- Confirm output folder before exporting.
- Name the output with side, band, type, plate, and final/trial status.
